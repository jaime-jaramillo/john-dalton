01 Estructura con sentido

HTML describe; Hugo une las piezas

HTML es el lenguaje que organiza el contenido. Sus etiquetas indican qué función cumple cada parte. Elegirlas por su significado se llama usar HTML semántico.

Mapa del documento

Selecciona una pieza. Con teclado, llega con Tab y actívala con Intro.

<header> Presentación <nav> Navegación
<main> Contenido principal <section> Un tema <article> Una ficha independiente <aside> Información relacionada
<footer> Cierre del sitio

Sin JavaScript puedes seguir los enlaces y leer todas las piezas debajo.

<header>

La presentación del sitio

Reúne la identidad del proyecto y su presentación. En la base de John Dalton se incluye con el parcial header.html.

<header>
  <a href="/">John Dalton</a>
  <p>Aprendemos sobre salud visual</p>
</header>

Un parcial es una plantilla pequeña que se inserta dentro de otra.

<nav>

Los caminos de la página

Agrupa los enlaces de navegación. Si hay varios menús, sus nombres deben permitir distinguirlos.

<nav aria-label="Módulos de la guía">
  <a href="#estructura">HTML y Hugo</a>
  <a href="#taller">Taller de código</a>
</nav>

Los enlaces reales de esta guía usan identificadores: nombres únicos como taller.

<main>

Lo principal de cada página

Contiene el contenido central. El encabezado y el pie compartidos quedan fuera de este elemento.

<a href="#contenido">Saltar al contenido</a>
<main id="contenido">
  <h1>Guía para estudiantes</h1>
</main>

La base de Hugo ya añade main. Los módulos no deben repetirlo.

<section>

Un grupo con un tema

Separa una parte temática, como los módulos de esta guía. Un título ayuda a entender su propósito.

<section id="taller" aria-labelledby="taller-titulo">
  <h2 id="taller-titulo">Taller de código</h2>
  <p>Probemos un temporizador.</p>
</section>

aria-labelledby toma el nombre de la sección del título indicado.

<article>

Una pieza que tiene sentido por sí sola

Sirve para contenido independiente. Una ficha de un programa de apoyo puede tener su propio título, descripción y enlace.

<article>
  <h3>Temporizador de práctica</h3>
  <p>Un ejercicio de diez segundos.</p>
</article>

No toda caja visual necesita article: elige según el contenido.

<aside>

Una explicación complementaria

Guarda contenido relacionado que se puede leer por separado, como una recomendación para desarrollar el ejercicio.

<aside aria-labelledby="nota-titulo">
  <h2 id="nota-titulo">Antes de empezar</h2>
  <p>Guarda una copia de tus archivos.</p>
</aside>

Su apariencia depende del CSS; no tiene que estar a la derecha.

<footer>

El cierre y la autoría

Puede reunir información del proyecto y enlaces complementarios. En este sitio, footer.html contiene el cierre compartido.

<footer>
  <p>John Dalton · Proyecto educativo</p>
</footer>

No añadas una licencia ni un sello de cumplimiento que el proyecto no haya definido o comprobado.

Del archivo al navegador

Hugo crea HTML a partir de contenido y plantillas. El archivo content/guia-estudiantes.md elige student-guide como plantilla. La base aporta el documento común; esta plantilla ordena sus parciales:

{{ readFile "layouts/student-guide.html" }}

El navegador recibe HTML, CSS y JavaScript; no necesita ejecutar Hugo. CSS define la presentación y JavaScript añade las interacciones.
