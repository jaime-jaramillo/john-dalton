05 Tu siguiente paso

Tres retos para practicar

Haz cada cambio en una copia del ejemplo. Primero intenta resolverlo; después abre la solución y comprueba el resultado en el navegador.

CSS · Colores

1. Crea una variante de alto contraste

Añade la clase alto-contraste al body del ejemplo. Usa fondo negro y texto blanco, incluidos la tarjeta y sus títulos. Conserva un foco visible.

Ver una solución

Cambia la etiqueta de apertura a <body class="alto-contraste"> y añade al final de style.css:

body.alto-contraste,
.alto-contraste .timer {
  background: #000;
  color: #fff;
}
.alto-contraste h1,
.alto-contraste h2,
.alto-contraste .eyebrow,
.alto-contraste .time,
.alto-contraste a {
  color: #fff;
}
.alto-contraste :focus-visible {
  outline-color: #ff0;
}
.alto-contraste .skip-link {
  background: #000;
}

Revisa también los botones y el salto al contenido. La combinación negro/blanco tiene contraste 21:1; eso describe ese par, no una evaluación del sitio completo.

HTML · Estructura

2. Añade una ficha con sentido

Dentro de main, después de las secciones, añade una ficha independiente sobre el experimento. Dale un título y explica qué has cambiado sin prometer resultados médicos.

Ver una solución 
<article>
  <h2>Mi prueba de veinte segundos</h2>
  <p>Cambié data-duration a 20.
  Probé iniciar, pausar y reiniciar
  usando solo el teclado.</p>
</article>

El título tiene nivel h2 porque depende del título principal h1. La ficha cuenta un experimento completo.

JavaScript · Estados

3. Mejora el aviso final

Cambia el mensaje que aparece al terminar. Conserva role="status", no muevas el foco y evita avisos cada segundo. Comprueba que puedes iniciar otra cuenta.

Ver una solución

En script.js, reemplaza solo el mensaje dentro de if (restante === 0) por:

estado.textContent =
  'La práctica terminó. Puedes iniciar '
  + 'otra cuenta cuando quieras.';

Conserva detener(), terminado = true y el cambio de nombre del botón. Así el temporizador puede volver a empezar.

Ampliación opcional: si exploras un sonido, permite que la persona lo solicite con un botón. No lo reproduzcas automáticamente ni lo uses como único aviso.
